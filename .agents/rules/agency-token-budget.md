# Project token + agency rules

- Prefer graphify / narrow explore; read ≤3 focused files before clarifying or editing.
- Route substantive git-repo work via `agency-project-gateway` first, then `agency-chief-of-staff` or specialists with a **context packet**.
- UI/design: Lazyweb refs → Stitch design → implement (`agency-ui-pipeline` skill).
- Architecture diagrams: `agency-archify` once per map; link HTML paths — do not paste IR dumps.
- Canonical UI agent: `agency-ui-ux-designer`.
- Do not paste huge dumps — use paths and MCP tools.
- Keep diffs minimal; no drive-by refactors or unsolicited markdown docs.
