# Agency rich UI

Product UI screens must ship premium motion. Follow skill `agency-rich-ui` (+ `kits.md`).

- Web marketing / greenfield: agency web motion language (optional demo: ahsanislam.com) (or Motion + Magic UI on React).
- Android / KMP / iOS: first-party Compose / SwiftUI animation; keep project brand tokens.
- Static screens = failed handoff. Product UI motion is not YAGNI (see ponytail).
- Routers put a `Motion:` line in the context packet before UI specialists.
